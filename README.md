# 평균 균형 조정실

초등학교 5~6학년 수학의 평균을 `전체 양을 고르게 나눈 값`으로 탐구하는 한국어 정적 웹앱입니다. 학생은 가상 자료를 살펴보고, 평균을 예측하고, 계산하고, 자료의 퍼짐과 한계를 근거 문장으로 설명합니다.

이 저장소는 Vite·React·TypeScript로 만든 서버 없는 SPA입니다. 앱은 서버·로그인·분석 추적·외부 AI API를 사용하지 않습니다. 균형 배송 작업대에는 글자·숫자 없는 로컬 생성 장식 일러스트를 사용하고, 학습 값과 조작은 모두 semantic DOM으로 제공합니다.

## 학습 목표

- 평균을 전체 양을 자료 개수만큼 고르게 나눈 값으로 설명합니다.
- 합계와 자료 개수로 평균을 계산하고 재배분 결과와 연결합니다.
- 평균이 같아도 자료의 퍼짐과 모양이 다를 수 있음을 비교합니다.
- 한 값의 변화가 합계와 평균에 미치는 영향을 설명합니다.
- 평균의 도움과 한계를 범위 또는 개별 값과 함께 판단합니다.

권장 대상은 초등 5~6학년이며, 한 차시 25~35분 활동을 기준으로 합니다. 2022 개정 교육과정 `[6수04-01]`의 평균 의미·계산·해석과 문제 해결·추론·의사소통·정보 처리 과정을 지원합니다.

## 4개 미션과 고정 자료

모든 자료는 검수된 가상 자료이며, 각 미션의 A 세트는 필수 학습 경로, B 세트는 같은 개념을 다시 적용하는 선택 도전입니다. 표시되는 값은 다음 계약과 같습니다.

| 미션 | 세트 | 자료 | 핵심 수학 |
|---|---|---|---|
| 1. 균형 배송 | A `balance-20-a` | `[2, 4, 6, 8]` → `[5, 5, 5, 5]` | 합 20, 평균 5 |
| 1. 균형 배송 | B `balance-24-b` | `[1, 5, 7, 11]` → `[6, 6, 6, 6]` | 합 24, 평균 6 |
| 2. 평균 쌍둥이 | A `twins-4-a` | `[4, 4, 4, 4]` 대 `[1, 3, 5, 7]` | 자료 A/B 평균 4, 범위 0/6 |
| 2. 평균 쌍둥이 | B `twins-6-b` | `[6, 6, 6, 6]` 대 `[2, 4, 8, 10]` | 자료 A/B 평균 6, 범위 0/8 |
| 3. 튀는 값 경보 | A `outlier-5-a` | `[4, 5, 5, 6]` → `[4, 5, 5, 10]` | 합 +4, 평균 5→6 |
| 3. 튀는 값 경보 | B `outlier-6-b` | `[5, 6, 6, 7]` → `[5, 6, 6, 15]` | 합 +8, 평균 6→8 |
| 4. 대표값 심의 | A `review-cards-a` | `[2, 2, 2, 2, 12]` | 평균 4, 범위 10 |
| 4. 대표값 심의 | B `review-baskets-b` | `[1, 1, 1, 9]` | 평균 3, 범위 8 |

균형 배송은 가상 포장 상자 속 구슬, 평균 쌍둥이는 가상 선반의 독서 카드, 튀는 값 경보는 가상 수확 바구니, 대표값 심의는 가상 보급 상자를 사용합니다. 실제 학생의 자료는 사용하지 않습니다.

## 로컬 설치·실행·검증

Node.js와 npm이 있는 환경에서 저장소 루트에서 실행합니다.

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run test:e2e
npm run build
npm run preview -- --host 127.0.0.1
```

`npm run dev`는 개발 서버를 열고, `npm run test:e2e`는 Playwright Chromium으로 브라우저 경로를 확인합니다. 로컬 E2E는 기본 4174 포트를 사용하고, CI는 4173을 사용합니다. 필요하면 `PLAYWRIGHT_PORT=4188 PLAYWRIGHT_REUSE_SERVER=false npm run test:e2e -- --project=chromium`처럼 포트와 서버 재사용을 명시할 수 있습니다. `npm run build`는 `dist/`에 정적 산출물을 만들며, `npm run preview -- --host 127.0.0.1`는 그 빌드를 로컬에서 확인합니다. 이 저장소의 의존성 재현에는 `npm ci`만 사용합니다.

## 학습 흐름과 키보드 조작

시작 화면에서 미션을 고르면 `상황 확인 → 평균 예측 → 재배분 또는 계산 → 비교 → 근거 설명 → 미션 결과` 순서로 진행합니다. 균형 배송의 재배분은 한 번에 1개를 꺼내고 넣는 버튼으로 수행하며, 드래그 없이 완료할 수 있습니다.

- `Tab`과 `Shift+Tab`으로 초점을 이동하고 `Enter` 또는 `Space`로 버튼·선택지를 실행합니다.
- 수량을 바꾸면 화면의 상태 영역이 변화를 알려 줍니다.
- 균형 배송에서는 `마지막 이동 취소`로 바로 앞 이동을 되돌릴 수 있습니다.
- 현재 단계의 다음 행동 버튼 하나만 강조되며, 대화상자는 `Escape`로 닫고 열었던 `업데이트 내역` 버튼으로 초점이 돌아옵니다.
- `prefers-reduced-motion: reduce`에서는 깜빡이는 `gi-pulse` 대신 굵은 테두리와 `다음 행동` 문구를 표시합니다.
- 단계가 바뀌면 새 `main` 영역으로 초점이 이동하고, 진행 단계에는 완료·현재·예정 상태가 글자로도 표시됩니다.
- 375px 너비와 큰 글자에서도 핵심 흐름은 한 열로 표시되며, 색만으로 상자나 자료를 구분하지 않습니다.

교사용 요약은 데스크톱·인쇄에서 표로, 640px 이하에서는 줄바꿈되는 카드 목록으로 표시합니다. VoiceOver와 실제 보조공학 사용자 승인은 이번 자동 검증 범위에서 제외했으며, 키보드·DOM 접근성·axe 검사를 수행합니다.

## 저장·개인정보·안전

기본 진행 상태는 현재 탭의 `sessionStorage`에만 유지됩니다. 학생이 `이 기기에 진행 저장`을 선택한 경우에만 같은 기기의 `localStorage`에도 저장됩니다. 두 저장 방식 모두 다른 기기로 공유되거나 동기화되지 않습니다. 결과 화면의 전체 삭제는 확인 뒤 탭 저장과 기기 저장을 함께 지웁니다.

이 앱은 이름, 학번, 성적, 키, 몸무게를 입력받거나 저장하지 않습니다. 실제 학생 집단을 평균으로 서열화하지 않으며, 학생 간 순위·계정·온라인 대시보드·광고·분석 추적·파일 업로드를 제공하지 않습니다. 교사용 출력은 학생 식별 정보가 없는 활동 요약입니다.

이 활동은 실제 세계를 정밀하게 측정하지 않는 교육용 이산 모형입니다.

평균 하나가 공정성이나 개인의 가치를 결정하지 않습니다.

## MVP 범위와 제외 항목

현재 MVP에는 4개 미션과 8개 고정 자료, 버튼 기반 재배분, 평균 계산, 전후·분포 비교, 근거 선택과 문장 틀, 근거 중심 결과 및 익명 교사용 요약, 반응형·키보드·모션 감소 대응이 포함됩니다.

다음 기능은 현재 범위에 포함하지 않습니다.

- 실제 학급 자료 수집·업로드·동기화
- 자유 서술 자동 채점이나 생성형 AI
- 중앙값·최빈값의 본격 비교 및 그래프 작도 도구
- 교사 계정, 온라인 대시보드, 학생 간 순위
- 실측 센서·마이크·신체 자료 입력

## 이미지·데이터 표현 원칙

`src/assets/notebook/bench-illustration-v2.png`는 평균 학습의 값을 전달하지 않는 빈 트레이 장식입니다. 생성 이미지에는 문구·숫자·수식·표·로고를 넣지 않았고, 실제 수량·평균·균형 상태·버튼은 DOM과 기존 도메인 상태가 소유합니다. 이미지가 로드되지 않아도 같은 학습 정보를 읽을 수 있으며, 외부 이미지·폰트·CDN·추적 요청은 사용하지 않습니다.
